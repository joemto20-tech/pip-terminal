# HAM Field Network v1.4.0

Adds the Field Notes keyboard back into the working HAMCo build.

Install:

```text
/APPINFO/ham.info
/HOLO/HAM/APP.JS
/HOLO/HAM/HAM_DATA.JSON
```

Access code:

```text
4769
```

Notes keyboard controls:

```text
Select + NEW NOTE     Create a new note
Select existing note  View note
Press while viewing   Edit note
Left wheel            Change character
Right wheel           Move cursor
Press                 Insert selected character
Shake/tap             Save and return to notes
```

Notes save automatically into:

```text
/SETTINGS/HAM_STATE.JSON
```
